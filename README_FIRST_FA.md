# PromptAll Android v3.10.0 — PromptAll AI + پرداخت درون‌برنامه‌ای کافه‌بازار

این بسته برای ریپوی فعلی `omidqodsi-netizen/promptall-android` با مبنای نسخه 3.9.1 آماده شده است.

## روش ساده برای شما (بدون اجرای اسکریپت روی کامپیوتر)

محتویات این ZIP را با حفظ مسیر پوشه‌ها روی **ریشه همان Repository** آپلود کنید و فایل‌های هم‌نام را Replace کنید. مهم است که این فایل‌ها دقیقاً در مسیر خود قرار بگیرند:

- `.github/workflows/build-apk.yml`
- `apply_patch.py`
- `app/src/main/java/ir/promptall/app/ai/AiImageScreens.kt`
- `app/src/main/java/ir/promptall/app/ai/AiImageViewModel.kt`
- `app/src/main/java/ir/promptall/app/data/remote/AiImageApi.kt`
- `app/src/main/res/xml/file_paths.xml`

Workflow جدید قبل از Build، `apply_patch.py` را خودش اجرا می‌کند؛ بنابراین لازم نیست روی کامپیوتر Python یا Android Studio داشته باشید.

## پیش‌نیاز سمت سایت

نسخه `PromptAll AI Image Generator v1.0.25` باید روی سایت نصب باشد و در بخش «اپلیکیشن و کافه‌بازار»:

- ساخت داخل اپ فعال باشد.
- Package Name برابر `ir.promptall.app` باشد.
- SKU فعلی در سرور تنظیم شده باشد (`ai_image_single` برای واقعی یا `ai_image_test` برای تست صفرریالی).
- RSA عمومی بازار ثبت شده باشد.
- توکن API پیشخان بازار فقط روی سرور ذخیره شده باشد.

**توکن API پیشخان بازار هرگز داخل APK/GitHub قرار نمی‌گیرد.**

## طراحی UX نسخه جدید

- CTA بومی «با چهره خودت بساز» داخل صفحه تکی پرامپت تصویری.
- پرامپت به صورت خودکار از همان آیتم خوانده می‌شود؛ کاربر متن را دوباره وارد نمی‌کند.
- روند سه مرحله‌ای و واضح: «چهره → پرداخت → ساخت».
- انتخاب عکس از گالری یا دوربین، نمایش Preview و امکان تغییر قبل از خرید.
- قیمت از خود کافه‌بازار دریافت می‌شود؛ مبلغ داخل APK هاردکد نشده است.
- پرداخت فقط با کافه‌بازار در نسخه بازار؛ هیچ لینک پرداخت وبی داخل این مسیر وجود ندارد.
- Verify خرید روی سرور PromptAll انجام می‌شود.
- خرید مصرفی پس از تأیید توسط Poolakey Consume می‌شود و سرور وضعیت Consume را دوباره بررسی می‌کند.
- اگر ساخت AI بعد از پرداخت خطا بخورد، وضعیت خرید در سرور نگهداری می‌شود و کاربر «بدون پرداخت مجدد» Retry می‌کند.
- اگر اپ بعد از پرداخت بسته شود، رسید روی دستگاه ذخیره می‌شود و صفحه بازیابی خرید نمایش داده می‌شود.
- صفحه «پروفایل من / تصاویر ساخته‌شده» با گالری خصوصی، Preview، دانلود و اشتراک‌گذاری.
- دانلود خروجی با DownloadManager اندروید.
- پروفایل ناشناس برای اولین استفاده به‌صورت خودکار در سرور ساخته می‌شود؛ ورود اجباری قبل از اولین ساخت وجود ندارد.
