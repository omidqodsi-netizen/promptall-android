# PromptAll Android 3.8.1

## Fixes
- Generated AI prompt card is now vertically scrollable on small screens.
- When a generated prompt appears, the AI panel automatically scrolls to reveal it.
- The AI panel has a bounded responsive height so the bottom of long prompts is reachable.
- Release APK keeps ML Kit search behaviour but removes x86/x86_64 native libraries, reducing APK size substantially for real Android phones.

## Version
- versionName: 3.8.1
- versionCode: 30801

## Distribution
- ARM32 + ARM64 supported.
- x86/x86_64 emulator APKs are intentionally not included in the market release.
