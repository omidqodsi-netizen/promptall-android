# promptAll Native Android

اپلیکیشن Native اندروید برای نمایش پرامپت‌های سایت promptall.ir.

## قابلیت‌های پیاده‌سازی‌شده

- رابط کاملاً Native با Kotlin و Jetpack Compose
- تم دارک و نمایش Edge-to-edge
- گرید دو ستونه Masonry با حفظ نسبت واقعی تصاویر
- دکمه مینیمال کپی متن روی تصویر
- علاقه‌مندی آفلاین با Room
- قلب کوچک‌تر با ناحیه لمس استاندارد
- جست‌وجوی تأخیردار (debounced) در عنوان و متن پرامپت
- وضعیت مستقل خانه و جست‌وجو
- فید خانه تصادفی در هر اجرای اپ برای جلوگیری از تکراری شدن تجربه
- ردیف «آخرین پرامپت‌ها» در بالای خانه با دسترسی سریع به جدیدترین محتوا
- ردیف «آخرین پرامپت‌ها» هنگام اسکرول فید، در هر دو حالت تصادفی و آخرین‌ها با انیمیشن نرم جمع می‌شود و در ابتدای صفحه برمی‌گردد
- حالت «نمایش بیشتر» برای مرور آخرین پرامپت‌ها به ترتیب انتشار
- صفحه‌بندی و بارگذاری خودکار هنگام اسکرول
- کش آفلاین آخرین ۱۰۰ پرامپت مشاهده‌شده
- تازه‌سازی با کشیدن صفحه به پایین
- لودینگ اسکلتی هنگام دریافت اولیه
- اعلان درون‌برنامه‌ای برای پرامپت‌های جدید
- نوار ناوبری شناور روی محتوا
- صفحه اطلاعات نرم‌افزار
- صفحه جزئیات کامل پرامپت با تصویر Hero، متن کامل، کپی، علاقه‌مندی و اشتراک‌گذاری
- پیشنهاد «پرامپت‌های مشابه» با اولویت دسته و شباهت محتوایی
- باز کردن پرامپت در ChatGPT، Gemini و Grok با کپی خودکار متن قبل از خروج از اپ
- حفظ مسیر بازگشت بین پرامپت اصلی و پرامپت‌های مشابه
- جستجو با تصویر: انتخاب از گالری یا Share مستقیم از برنامه‌های دیگر
- پردازش تصویر روی خود گوشی با pHash/dHash/Histogram و برچسب‌های معنایی ML Kit محلی
- عدم ارسال یا ذخیره عکس خام کاربر روی سرور
- نمایش درصد شباهت و نتایج «همان تصویر / بسیار نزدیک / مشابه»
- سهمیه روزانه جستجوی تصویری با کنترل سمت سرور
- تنها مجوز مورد استفاده: اینترنت

## API مورد انتظار

`GET https://promptall.ir/wp-json/promptall/v1/prompts?page=1&per_page=20&search=`

نمونه پاسخ:

```json
{
  "items": [
    {
      "id": 11244,
      "title": "عنوان پرامپت",
      "prompt_text": "متن کامل پرامپت",
      "image": {
        "url": "https://promptall.ir/example.webp",
        "width": 1024,
        "height": 1536
      }
    }
  ],
  "page": 1,
  "total_pages": 10,
  "has_more": true
}
```

تا پیش از نصب افزونه API، نمایش خطای اتصال در اپ طبیعی است.


### API جستجو با تصویر (اختیاری و مستقل)

نسخه 3.7.0 در صورت نصب افزونه `PromptAll Image Search 1.0.0` از namespace جداگانه زیر استفاده می‌کند:

- `GET /wp-json/promptall-search/v1/status`
- `POST /wp-json/promptall-search/v1/search`

APIهای قدیمی `promptall/v1` بدون تغییر باقی مانده‌اند؛ در نتیجه نصب افزونه جدید نسخه‌های قدیمی اپ را از کار نمی‌اندازد.
