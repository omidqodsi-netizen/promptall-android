# Full Checkpoint v3.10.7

این بسته ادامه مستقیم v3.10.6 است و تمام اصلاحات خرید و بازیابی بازار آن نسخه را حفظ می‌کند.

## وضعیت فعلی
- Android versionName: 3.10.7
- Android versionCode: 31007
- Plugin companion: PromptAll AI Image Generator v1.0.29

## تغییرات این checkpoint
- جداسازی کامل نتیجه ساخته‌شده بر اساس postId برای جلوگیری از نمایش خروجی قبلی روی پرامپت جدید.
- پاک‌سازی session نتیجه هنگام ورود به Generator جدید.
- ذخیره مستقیم و قابل‌اعتماد تصویر در گالری/Pictures/PromptAll.
- حذف دکمه Share از تصاویر ساخته‌شده.
- بررسی زنده وضعیت فعال/غیرفعال قابلیت قبل از هر ورود به Generator.
- پشتیبانی از Kill-switch مستقل در افزونه بدون نیاز به حذف UI یا کد از APK.
